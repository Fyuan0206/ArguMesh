# ArguMesh（论脉）品牌规范

## 品牌核心

- 英文名：`ArguMesh`
- 中文名：`论脉`
- 品牌语：`把证据连成研究脉络`
- 定位：面向科研人员的证据驱动型文献研究工作台。

`Argu` 来自 argument，强调学术论证；`Mesh` 表示由论文、摘录、主张、证据和研究构想连接而成的网络。中文“论脉”同时表达论文脉络、论证脉络和研究思路的延续。

## Logo 含义

标志由三层语义组成：

1. 主轮廓是字母 `M`，对应 Mesh。
2. 下方折线和中轴构成打开的文献页。
3. 六个节点表示论文证据经过连接、核验后汇聚为研究判断。

资产：

- `public/argumesh-mark.svg`：方形品牌标志，用于 favicon、侧边栏和头像。
- `public/argumesh-logo.svg`：横版 Logo，用于 README、介绍页和宣传材料。
- `public/argumesh-mark.png`：`512 × 512` PNG 导出，用于不支持 SVG 的平台。
- `public/argumesh-logo.png`：`840 × 208` PNG 导出，用于文档和分享预览。

## 使用规则

- 标志四周至少保留其宽度 `1/6` 的安全空间。
- 方形标志最小显示尺寸为 `24 × 24 px`，横版 Logo 建议不小于 `180 px` 宽。
- 深色界面优先使用方形标志；浅色文档和介绍页优先使用横版 Logo。
- 不拉伸、不旋转、不替换品牌色，不给标志添加阴影或发光效果。
- 首次出现使用“ArguMesh（论脉）”，后续可简称“ArguMesh”或“论脉”。

## 兼容性说明

`paperidea-workbench` Worker 名称、`paperidea_*` 浏览器存储键、备份格式标识和 API service 名称属于已有技术接口，暂时保留，避免破坏线上部署和用户数据。它们不作为对外品牌名称使用。
