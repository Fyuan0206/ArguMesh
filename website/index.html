A CONNECTED RESEARCH WORKFLOW

科研不是一堆孤立的文件

而是一条从文献到写作、持续积累的证据链。

01

建立你的文献库

导入 PDF、DOI 或 arXiv 编号，整理阅读状态与标签。让一项研究的相关文献，从一开始就在一起。

文献管理 · 项目空间
02

读懂，也留下出处

在 PDF 中摘录、提问、记录。把段落保存为笔记、主张或证据，论文与页码始终跟随每一条发现。

PDF 精读 · 原文溯源
03

把论文放在一起比较

以论文为列、研究维度为行，建立证据矩阵。AI 辅助提取，你逐格核验并锁定可信结论。

证据矩阵 · 人工核验
04

从发现走向研究问题

连接发现、矛盾与研究缺口，把值得追问的线索变成研究问题。让每一个方向，都有证据可循。

研究脉络 · 问题演进
05

让研究继续向前

设计主实验与消融方案，导入结果并分析，再把结论带回研究问题。衔接论文写作，让过程与成果相互连接。

实验设计 · 结果分析 · 写作

在自己的电脑上，搭建自己的研究工作台。

查看安装指南进入在线工作台
从源码启动 · Node.js + pnpm
git clone https://github.com/Fyuan0206/ArguMesh.git
cd ArguMesh
pnpm install
pnpm run db:seed
pnpm run dev

本地开源版无需账号。在线工作台为独立部署，需使用已有账号登录。
